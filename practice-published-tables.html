● Practice · Putting it all together

What would it look like published?

Research articles don't print the raw output from SPSS or any other statistical software. They print a table built from it, with stars, notes and a few fit statistics. Each table here remakes a model you have already run in this series, on the same data, so you can practice reading the published format.

Every number on this page comes from real regressions and t tests on the site's data. Tap any number, column heading, variable name or the notes line to see what it means. Below each table you can open the SPSS output for the same analysis (and the Stata output, if you use Stata) and check that the numbers match.

Export style

In Tables 1 and 3, each model appears the way statistics programs export it, with raw variable names and each statistic in its own column.

Journal style

In Tables 2 and 4–8, several models sit side by side in columns, and each standard error sits in parentheses under its coefficient.

Comparison style

In Tables 9 and 10, group means sit side by side with a test of whether they differ, which is the way papers report differences of means.

The regression tables put stars on the coefficients and explain them in a notes line. They use * p < .05, ** p < .01, *** p < .001. The comparison tables print the p-values themselves instead of stars, as APA style does.
