What would it look like published?

Research articles don't print Stata output. They print a table built from it, with stars, notes and a few fit statistics. Each table here remakes a model you have already run in this series, on the same data, so you can practice reading the published format.

Every number on this page comes from a real regression on the site's data. Tap any number, column heading, variable name or the notes line to see what it means. Below each table you can switch to the Stata output for the same model and check that the numbers match.

Export style

Tables 1 and 3. One model, raw variable names, and a column for each statistic, the way statistics programs export it.

Journal style

Tables 2 and 4–7. Several models side by side, one per column, with each standard error in parentheses under its coefficient.

Both styles put stars on the coefficients and explain them in a notes line. These tables use * p < .05, ** p < .01, *** p < .001.
